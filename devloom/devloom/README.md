# DevLoom

DevLoom is a modular web platform designed for software engineers to share technical write-ups, tutorials, code snippets, and architecture discussions.

## Key Features
- **Categorized Posts:** Filter content by Tutorial, Snippet, Question, or Discussion.
- **Developer Vault / Library:** Bookmark articles to build a personal library.
- **Like & Comment System:** Engage with posts through interactive likes and comments.
- **Admin Dashboard:** Manage users, posts, and core platform metrics.
- **Markdown Support:** Full rendering support for technical Markdown content with code blocks.
